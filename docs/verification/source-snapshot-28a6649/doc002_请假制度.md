# 请假制度

## 总则

为规范员工请假管理，保障正常工作秩序，根据国家有关法律法规并结合公司实际，制定本制度。本制度适用于公司全体正式员工，试用期员工的请假参照执行。

员工请假应本着诚信原则，如实说明请假事由。请假期间的工作由直属主管安排他人承接，请假人应在离岗前完成必要的工作交接。各部门负责人应掌握本部门员工的请假情况，合理安排人员，避免因集中请假影响业务办理。人力资源部负责本制度的解释和修订。

## 事假

员工因个人事务需要请假的，应申请事假。事假需提前2个工作日在系统中提交申请，经审批后方可离岗。突发情况无法提前申请的，应在当天及时告知直属主管，并于返岗后补交申请。

事假期间不发放当日工资，当月事假天数在考勤中如实记录。事假不得用于处理与已批准的其他假期相冲突的日期。

## 病假

员工因病需要休息的，应申请病假。病假需在3个工作日内补交医院证明，连续病假超过3天的，需提供二级以上医院出具的证明。

病假期间的工资按国家和地方有关规定执行。员工不得以病假名义处理个人事务，一经查实按事假或旷工处理。

## 婚假与产假

员工依法登记结婚的，可享受婚假10天。婚假需在领取结婚证后6个月内使用，逾期未使用的视为放弃。婚假期间工资照常发放。

女员工产假、男员工护理假按国家和地方有关规定执行。员工申请婚假、产假时，应提交结婚证、出生医学证明等材料，由人力资源部核验。

## 请假审批流程

员工请假应在系统中填写请假类型、起止时间和事由。请假1天以内由直属主管审批；请假超过3天的，需部门经理审批，其余情形由直属主管审批。

审批通过的请假记录作为考勤依据。未经审批擅自离岗的，按旷工处理。员工返岗后应及时销假，未销假的按请假记录延续处理。
