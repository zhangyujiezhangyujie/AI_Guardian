# 内部操作规范

## 总则

为规范公司内部系统操作，保护客户数据和业务记录安全，制定本规范。本规范适用于所有接触公司业务系统的员工，包括正式员工、试用期员工和外包人员。

员工应按照岗位职责和授权范围操作系统，不得越权访问、修改或删除数据。发现异常操作或数据泄露风险时，应立即向部门经理和信息安全负责人报告。各部门负责人应组织本部门员工学习本规范，并将规范要求纳入新员工入职培训。

## 客户数据管理

客户数据只能在公司内网系统中查看，不得在公共网络环境下访问。员工因工作需要查询客户数据时，应遵循最小必要原则，仅查看与当前业务相关的内容。

禁止将客户数据导出到个人设备，禁止通过个人邮箱、即时通讯工具传输客户数据。因业务需要对外提供客户数据的，应经部门经理审批并做好脱敏处理。

## 业务记录操作

删除业务记录需部门经理审批，审批通过后由系统管理员执行。员工不得自行删除记录，也不得通过技术手段规避审批流程。

修改业务记录需留存操作日志，日志内容包括操作人、操作时间和修改原因。操作日志由系统自动记录，任何人不得删除或篡改。

## 账号与权限

系统账号禁止多人共用，员工应使用本人账号登录并妥善保管密码。密码应定期更换，不得将密码告知他人或记录在容易被获取的位置。

员工岗位调整或离职时，部门经理应及时通知系统管理员调整或注销账号权限。权限申请应说明用途和期限，超出期限的权限由系统管理员回收。

## 违规处理

违反本规范的，视情节给予警告直至解除劳动合同。造成客户数据泄露或公司损失的，公司保留追究法律责任的权利。

员工发现他人违反本规范的行为，可向部门经理或信息安全负责人举报，公司对举报人信息予以保密。
