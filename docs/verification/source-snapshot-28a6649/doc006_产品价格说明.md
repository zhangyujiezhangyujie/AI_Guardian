# 产品价格说明

## 产品线概览

公司面向家庭和企业客户提供智能安防产品，主要产品包括智能门锁、智能摄像头和智能门铃三大系列。产品支持手机应用远程查看与操作，可与公司统一的设备管理平台对接。

本说明所列价格为含税零售指导价，实际成交价格以销售合同为准。

## 智能门锁

智能门锁 A1 售价1299元，采用指纹、密码和卡片三种开锁方式，支持临时密码授权。产品适用于家庭入户门，安装后可通过手机应用查看开锁记录。

智能门锁 Pro B2 售价1899元，在 A1 的基础上增加人脸识别和远程视频查看功能，适用于对安全性要求较高的场景。

## 智能摄像头

智能摄像头 C3 售价399元，支持高清录像、移动侦测和双向语音。设备可本地存储，也可开通云存储服务，云存储服务需另行订阅。

摄像头支持壁挂和桌面两种安装方式，室外使用需选配防水外壳。

## 智能门铃

智能门铃 D1 售价259元，支持访客呼叫、视频对讲和移动侦测。门铃可与智能门锁联动，访客按铃时手机应用同步提醒。

门铃内置电池，正常使用情况下续航时间约为数月，具体时长与实际使用频率有关。

## 价格与折扣说明

企业客户单次采购满50台，可享受9折优惠。批量采购的具体折扣以销售合同约定为准，不与其他促销活动叠加。

以上价格不含安装服务费。安装服务由公司认证的服务商提供，费用根据现场情况另行报价。产品价格调整时，公司会提前在官网公示。

经销商价格另行制定，不适用本说明所列零售指导价。公司提供统一的产品资料和演示样机，销售人员应按照最新资料向客户介绍产品，不得承诺资料之外的功能。产品资料以官网发布版本为准，内部宣传材料应与官网保持一致。客户在购买前应确认产品型号与安装环境，避免因选型不当造成退换货。经销商应在授权范围内销售，不得跨区域低价倾销。
