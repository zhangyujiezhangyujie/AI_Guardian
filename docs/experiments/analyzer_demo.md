## 分词结果

| 输入 | 分词结果 |
| --- | --- |
| 员工一年有多少天年假 | 员工 / 一 / 年 / 有 / 多少 / 天 / 年假 |
| 正式员工每年享有15天带薪年假，试用期员工不享有年假。 | 正式 / 员工 / 每年 / 享有 / 15 / 天 / 带 / 薪 / 年 / 假 / 试用期 / 员工 / 不 / 享有 / 年 / 假 |

逐词验证：

| 词 | 分词结果 | 是否成词 |
| --- | --- | --- |
| 年假 | 年假 | 是 |
| 带薪年假 | 带 / 薪 / 年假 | 否（“带薪”未成词） |
| 年休假 | 年 / 休假 | 否 |
| 请假、事假、病假、婚假 | 各自成词 | 是 |
| 报销、住宿、出差、保修、退货、迟到、旷工、福利、体检、审批、删除 | 各自成词 | 是 |
| 餐费补贴 | 餐费 / 补贴 | 是（两个词） |
| 内网 | 内 / 网 | 否 |

结论：**“年假”能正确切分，“带薪年假”不能**——单独输入时切成“带 / 薪 / 年假”，在正文语境中进一步切成“带 / 薪 / 年 / 假”；`内网`、`年休假` 同样被拆。这与任务卡阶段一第 4 条的验收点“年假、带薪年假能被正确切分”只达成一半。

## 结论与后续

1. 正常问题的 Top 1 都落在正确片段上，“年假”问题即使查询词与索引切分不完全一致，也仍由“员工”“天”“年”等词把正确片段排到第一。
2. 食堂问题的最高分只有 0.5262，且前三条完全不相关。**当前 min-score 必须大于 0.53 才能让 SC07 检索为空**，同时不能压掉正常问题——正常问题 Top 1 分数在 3.4 以上，留有余量，阶段二按 15 题分数表正式定阈值。
3. 分词不稳定（同一词在不同语境下切分不同）没有造成 Top 1 失败，但会影响两字词的召回。阶段二用 10 题命中率实验量化：若命中率不达标，再向成员 1 提契约变更，候选方案是“检索器内部增加 bigram 副字段”，或改用 CJKAnalyzer。
4. Lucene 9.11 的 `SmartChineseAnalyzer` 只支持自定义停用词，不支持自定义词典（`javap` 确认只有 `getDefaultStopSet`、两个构造器和 `createComponents`），所以“给词典补词”这条路走不通，只能靠停用词、同义词或换分析器。
